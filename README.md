Adidas Dynamic Web Scraper
Скрипт на Python для сбора данных с коммерческих сайтов.

Обходит антибот-защиту через Selenium.

Автоматически кликает на окна с куки.

Имитирует прокрутку человека и собирает скрытые элементы.

Очищает данные (цены) от текстового мусора через регулярные выражения (Regex).

Автоматически отправляет собранную базу в Telegram-бота.
